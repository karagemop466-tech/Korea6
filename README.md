# Free Time Vacation

A static, radio-first Bay Area sports calendar dashboard. Open `index.html` locally or publish the repository with GitHub Pages.

## Verification approach

The dashboard intentionally does not fabricate game rows, durations, airtime, or vacation windows. A day with missing coverage is **not verified free**. See [Flagged for Review](review.html) for unresolved inputs and the official schedule references. Schedule data should only be added with a source URL attached to each entry and a clearly stated verification status.

## Pages

- `index.html` — landing page, date navigator, coverage categories and source register.
- `review.html` — explicit gaps and unverified matters.

All displayed calendar times are intended to be Pacific local time (`America/Los_Angeles`), accounting for PST/PDT. No game schedule data is currently included.
